## 2. Layer Definitions (Compatible with Existing Repository)

### 2.1 Layer 1 — Application Shell, Providers, Routing, Global Composition (`src/App.tsx`, `src/auth.tsx`, `src/routes.tsx`, `src/app/navigation.ts`, `src/app/composition/useCases.ts`)

**Responsibility:** Compose providers (`ErrorBoundary`, `ThemeProvider`, `NetworkStatus`, `PwaUpdatePrompt`, `AppProvider`, `AuthProvider`, `ToastProvider`, `ConfirmProvider`), define routes with guards (`RequireAuth`, `RequireAdmin`), manage global session/reconciliation (`AppContext`), manage navigation registry (`navigation.ts`), create lazy repository bundle (`useCases.ts`).

**Public API / Contract:** `App` exports the composed root; `routes.tsx` exports route table (`routes` array); `navigation.ts` exports `NAVIGATION_ITEMS` (canonical registry feeding sidebar, mobile menu, header title, global search); `useCases` exports lazy `useCases` facade; `auth.tsx` exports `useAuth` hook; `AppProvider` exports `useApp` context.

**Ownership rules:** Only `App.tsx` and `routes.tsx` import `AppProvider`, `AuthProvider`, `ConfirmProvider`, `ToastProvider`, `ErrorBoundary`. Only `navigation.ts` feeds `Sidebar.tsx` and `GlobalSearch.tsx`. Only `AppProvider` manages `session` state and `center` reconciliation (`ARCHITECTURE.md` §4; `FINAL_INDEPENDENT_REVIEW.md` §2.2). `useCases.ts` creates repository bundle lazily; `createRepositoryBundle()` supports Supabase only (`ARCHITECTURE.md` §3; `ARCHITECTURE.md` §10 — Tauri backend rejected; desktop is prototype only).

**Import boundaries:** `pages/` imports `useCases`, `useAuth`, `useApp`, `useTranslation`, shared components (`PageHeader`, `ScreenState`, `Modal`, etc.), `navigation.ts`. `pages/` does NOT import `AppProvider`, `routes.tsx`, `navigation.ts` directly (only through `useNavigate` or `useTranslation` if needed). `shared/components/` does NOT import `pages/`. `domain/` does NOT import `application/` or `infrastructure/`. `application/` imports `domain/` only. `infrastructure/supabase/` implements `domain/ports/`. `app/composition/` imports `domain/` and `infrastructure/` but not `pages/` or `shared/components/` (except through `useCases` facade).

**Evidence:** `ARCHITECTURE.md` §2, §3, §4, §5, §10; source (`App.tsx`, `routes.tsx`, `navigation.ts`, `useCases.ts`, `auth.tsx`, `AppProvider`); `FINAL_INDEPENDENT_REVIEW.md` §2.2, §2.4.
