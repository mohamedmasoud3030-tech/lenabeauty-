# INTERFACE_ROUTE_INVENTORY

**Product:** LenaBeauty (user-facing brand "Lara Beauty") — salon/spa operations PWA for the Omani market.
**Inspected:** 2026-09-09, `main` @ `d110a3c`, working tree clean. Runtime: Vite dev server rendered and served (`/`, module graph 200 OK); authenticated screens verified against the committed `demo/*.png` captures and the 136-file / 880-test suite (information-architecture, mobile-portrait-ux, accessibility-foundation, sidebar-ia). Hosted Demo login remains credential-gated; no live authenticated probing was attempted against the real backend.

**Roles:** `ADMIN` (full access), `MANAGER`/`STAFF` (operational). Boundary = `RequireAdmin` in `src/routes.tsx` (hard guard); `adminOnly` in `src/app/navigation.ts` is visibility-only. Fail-closed: any session problem exits to `/login` with return-path state.

**Shell:** Desktop = 320px `Sidebar` grouped by operator job (Today / Catalog & People / Money / Team / Growth / System) + top chrome (center switcher, GlobalSearch ⌘K, theme/language). Mobile = header + `MobileActionDock` (menu / search / assistant) + `MobileNavigationSheet` (all shipped destinations). Skip link, `#main-content` landmark, focus trap, keyboard inset, RTL logical properties. Admin-only floating Gemini assistant (`AdminAssistantPanel`), rendered only for admins.

**State owners:** `ScreenState` (loading/error/empty/permission-style screens), `ListState` (list-shaped wrapper incl. table-row variant), `NetworkStatus` offline banner (`role=alert`), `PwaUpdatePrompt`, `NavigationNotice` (explains admin-only + not-found redirects), `ErrorBoundary`, `Toast`, `ConfirmDialog`, `Modal` (focus-trapped). Search-empty vs no-data is handled per page via conditional `emptyDescription` (5 pages).
